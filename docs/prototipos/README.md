# Prototipo visual histórico

`Web1Prueba.html` y `styles.css` corresponden a un prototipo visual temprano de MSDentalSys.

Estos archivos fueron utilizados como referencia de diseño. No forman parte de la aplicación ASP.NET Core MVC ejecutable.

El prototipo contiene datos ficticios. La aplicación actual se encuentra en `src/MSDentalSys.Web` y las pruebas reales en `tests/MSDentalSys.Tests`.
